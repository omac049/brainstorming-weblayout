Mobile-First Philosophy

UAGC paid traffic is >70% mobile. Contentsquare behavioral data shows:

  • Frustration score: 44/100 site-wide
  • Rage-click recurrence: 3.23× on hero RFI form (users tapping repeatedly)
  • Scroll depth: Only 11.7% on homepage (most mobile users see positions 1–3)

Because of this, Mobile Experience carries 25% weight (up from 5%) and layouts that score well on desktop but poorly on mobile receive an additional penalty.

Score Formula

Total = Σ(dimension_score × weight) − anti_pattern_penalty − desktop_penalty Where: dimension_score = 0–100 per dimension anti_pattern_penalty = points for wrong module/page-type combos desktop_penalty = applied when desktop dims > 60 but mobile < 40 = (desktop_avg − mobile_score) × 0.15 + multi-column penalty (if ≥3 grid modules & mobile < 50) + sidebar penalty (FORM-04 on non-blog)

Desktop Penalty

Applied when a layout is desktop-biased — scoring well on content-heavy dimensions (Content, Discovery, Social) while neglecting mobile:

  • TRIGGER Desktop avg > 60 AND mobile < 40
  • FORMULA (desktop_avg − mobile_score) × 0.15
  • EXTRA +4 pts if ≥3 multi-column modules with mobile < 50
  • EXTRA +3 pts for sidebar form (FORM-04) on non-blog pages

Rationale: Multi-column grids (PROG-01, PROG-03, FIN-02, TRUST-03) become single-column stacks on mobile, doubling scroll distance. Layouts that load up on these desktop patterns without mobile compensation are penalized.
