5. Page build — -op variations

What to ship

  • Rename each *-omarproject preview to its -op path (table above). 301 the old preview to the new path.
  • Keep each page's own layout: Request Info keeps the full stack; Degree Programs keeps the program explorer; Online College Courses stays lean with the skepticism-buster section.
  • Treatment: content-rich Omar module stacks (FAQ / info density). That is the test — not a bare RFI.
  • Keep working: Lead API submit, sourceID / UTM pass-through, consent, thank-you redirect, mobile layout, sticky RFI.
  • Do not change mid-test: path, major module order, or form field set.
  • SEO: paid LPs — noindex; confirm robots/canonical with SEO so test arms don't create indexation noise.

6. Form parity

Each -op page uses the same form fields and program options as its control (including whether Undecided appears). Only the page content changes. Side-by-side field list before launch.

7. Optimizely setup

Experiment OP Pages Reskin (project 18792324065, experiment 4675402130522112) already targets all three control URLs, 50/50. Three fixes before real traffic sees it:

Fixes before launch

  1. Remove the audience gate. It's limited to the Noble UTM Test 2 audience (?noble_test2=true), so only test links see it today.
  2. Change the redirect from adding -omarproject to swapping the version for -op (only after the -op pages return 200): 
    var path = window.location.pathname.replace(/\/+$/, "");
return window.location.origin + path.replace(/-v\d+$/, "-op") +
  window.location.search + window.location.hash;
  3. Keep the split at 50/50 and confirm the three control URLs in targeting.

Rules

  • Do not also A/B inside Meta Ads Manager or Google Ads — one split, in Optimizely.
  • Ad final URLs stay on the control paths (e.g. Meta stays on request-info-v5) so platforms don't relearn.
  • request-info-v5 gets Facebook and Google Display traffic — Eric reads results by channel; don't pool.
  • Optimizely metrics (primary: Mid-Page RFI Submit; plus thank-you views, form steps, header / sticky / apply clicks) are on-page signals only. The win call comes from BigQuery (section 2).
  • Soft-build before Dec 1; go live only after the freeze.
